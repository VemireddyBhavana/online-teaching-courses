# 🎓 LearnHub - Online Teaching Courses Platform

LearnHub is a modern and responsive Online Learning Platform built using **HTML, CSS, and JavaScript**. It provides an interactive learning experience where students can explore courses, enroll, track their progress, manage their learning journey, and more using **Local Storage**.

---

## 🚀 Live Features

- 🏠 Beautiful Landing Page
- 📚 Browse Online Courses
- 🔍 Search Courses
- 🎯 Filter Courses by Category & Level
- 📖 Course Details Page
- ✅ Course Enrollment
- ❤️ Wishlist
- 🎓 My Learning Dashboard
- 📈 Course Progress Tracking
- 🏆 Certificates Page
- 👤 Student Profile
- ⚙️ Settings Page
- 🌙 Dark / Light Mode
- 💾 Local Storage Integration
- 📱 Fully Responsive Design
